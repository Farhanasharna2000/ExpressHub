# Failed deliveries and returns

Sometimes a parcel cannot be delivered, for example when nobody is available to receive it.

## When a delivery fails

The courier marks the shipment Failed from Out for delivery and must add a note explaining why. The failure is recorded on the timeline, and if email notifications are on, the customer gets an email.

## What happens next

Only an admin can decide what happens after a failure. The admin can send the shipment back to In transit for another delivery attempt, possibly with a different courier, or mark it Returned. Returned is final. Admins can also refund a failed or returned shipment.
